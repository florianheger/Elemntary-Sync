# Feature: Dropbox
This file contains all the functionality with the Dropbox.

## Requirements:
1. Listen to changes in the folder "Apps/WahooFitness". Changes should be detected after a maximum of one minute.
2. Download the file and move it in the dropbox to the subfolder "Apps/WahooFitness/Processed"
3. Call the function "ProcessFitFile(file)" with the .fit file that was downloaded.
